# Synthetic data and augmentation — specification, generator, validation (2026-10-20)

Code: `src/synth/` (format simulator + ECG expanded-data experiments), `src/inhouse_bh/` (breath-hold windows, augmentation, simulator-backed windows). Policy: `CLAUDE.md` §4.
Synthetic recordings are **simulator outputs, not human recordings and not independent subjects**; their manifest says so (`not_a_human_recording: true`).

## 1. Real-data specification (measured; `results/synth/spec/`)
`python3 -m src.synth.spec` analyses the 15 in-house logs ≥ 600 s (12 with a usable ECG). Measured: fs 238.1–243.2 Hz (median 243.0), timestamp step 4112–4200 µs (SD 0.3–0.5 µs), HR 47.6–79.1 bpm (p5–p95), QRS FWHM 10.6–28 ms, hf noise 13–58 LSB, baseline wander SD 40–380 LSB, accel |g| 984–1005 mg, accel noise 1.5–5.4 mg (20–60 Hz band), breathing 0.18–0.45 Hz (median 0.32), breathing-band RMS 0.13–2.4 mg (28× between sessions), temperature 22.7–40.1 °C; file = comma-delimited, 16 columns (`time[us]`, acc LSB/mg ×3, gyro LSB/dps ×3, temp LSB/°C, `ah_qvar[LSB]`), conversions 0.061 mg/LSB, 0.004375 dps/LSB, temp = 25 + LSB/256; all session-2 logs end in one truncated row. 12 per-recording median beats (R polarity negative in 9/12) serve as the morphology library.
**Not measured (simulator assumptions, listed in the spec file):** respiratory modulation depth of ECG amplitude, hold kinematics (ramp 0.8 s, recovery gasp), motion-artefact statistics, gyro coupling, 50 Hz tone, EMG/EOG-tile QVAR content (the real EMG/EOG-labelled tiles show no recognisable biosignal), temperature course, inter-session electrode variation (one session per person).
**Known data-quality caveat:** in-house HRV statistics (RMSSD up to 439 ms) are inflated by R-peak detector errors on noisy tiles, so the simulator uses literature-style HRV ranges (SDNN 25–90 ms) rather than those values.

## 2. Simulator (`src/synth/physio.py`, `render.py`)
Beat-level engine, vectorised over a batch: RR = RR0·(1 + RSA·sin φ_resp + LF·sin φ_LF + event modulation) + white noise; breathing phase drifts (AR(1) on log-rate) and drives RSA, the ECG-amplitude (EDR) modulation and the accelerometer breathing, so channels stay coupled. Events (voluntary hold / central / obstructive) come from an explicit schedule; apnea-like events add progressive bradycardia then a post-event surge (CVHR), holds a mild version. Ectopics, missed beats and R-peak jitter are added at beat level. The renderer places measured beat templates (time-stretched ±15%) at the beat times, adds wander (incl. respiratory), hf noise, 50 Hz tone, offset, quantisation to int LSB; accelerometer = tilted gravity (renormalised after posture steps) + breathing + noise + motion bursts + optional sync taps (saturating at ±2 g); EMG/EOG tiles follow the audit (clipped / near-flat QVAR). Timestamps: µs integers with the measured step and jitter. Ground truth (event boundaries, taps, beat times) is written from the schedule (`<id>.truth.json`). Deterministic per (profile, seed). **Joint amplitude/noise sampling** (R amplitude bootstrapped from the measured values, noise = amplitude/SNR with SNR 8–80, noisy profiles 3.5–8) was added after the first validator run showed that independent sampling produced undetectable ECG.

## 3. Datasets (`python3 -m src.synth.gen --size pilot|medium|large`, `data/synthetic/`, gitignored, manifest per recording)
pilot 20 × 10 min, medium 100 × 30 min (CSV), large 400 × 30 min (`--fmt npz`); sizes configurable (`--n --minutes`). Scenario mix 40% voluntary-hold sessions (3–9 holds of 5–60 s, rest ≥ max(60 s, 3×hold), optional start/end sync taps), 30% apnea-like event nights, 30% baseline; tile mix 70% ECG / 15% EMG / 15% EOG; quality mix good/noisy/poor-breathing. Manifest fields: id, generator version, seed, full profile, fs, channels, duration, events with sample indices, taps, head hash, spec hash, generation time, validation status.

## 4. Validation (`src/synth/validate.py`, independent of the generator)
Required: columns/order, no NaN, strictly increasing timestamps, fs 230–250, jitter ≤ 5 µs, start offset, LSB↔mg/dps consistency, |g| 940–1050, no ±2 g saturation, temperature range, int16, no flat run > 2 s and < 1% clipping on ECG tiles, HR 40–120, < 5% implausible RR, detected beats within 8% of simulated beats. Optional (reported): breathing-peak frequency, hold effort drop where breathing amplitude > 0.5 mg. Results, real-vs-synthetic comparison, domain-classifier AUROC, diversity and near-duplicate checks: `results/synth/qc_*/`.

## 5. Augmentation
*ECG sequences (`src/synth/augment.py`)*: gain, RR jitter, amplitude noise, ±2-step shift, ±8% time-warp, slow amplitude drift, premature-beat insertion, 1–3-step dropout; sets `augA` (conservative) and `augB` (channel-specific) plus each component alone. *Breath-hold windows (`src/inhouse_bh/augment.py`)*: gain, joint small rotation (axis relations preserved), white noise, slow drift, ±6% time-warp, band-edge variation. Applied only to training windows.

## 6. Leakage controls
ECG experiments: simulator priors (RR, HRV, amplitude, gap rate) are re-estimated per fold from the fit records only; validation/early stopping/threshold use real validation records; the held-out record never touches generation. Breath-hold experiments: the format-simulator spec is re-fitted **without session 1** (`SYNTH_SPEC_DIR=results/synth/spec_noS1`); SSL data exclude session 1; synthetic recordings failing the separability gate (simulated holds not clearly quieter than their own baseline) are rejected and counted.
