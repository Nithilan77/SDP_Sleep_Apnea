Breath-hold demonstration · upload & inference

Task: voluntary breath-hold-like low-effort windows (in-house feasibility track). This page does not screen for sleep apnea and nothing here is clinically validated. The models were trained on voluntary breath-holds from one volunteer's session (real windows only; augmentation and simulator data were evaluated and did not help, see the model notes below); breath-holds are not apnea events. Sleep-apnea screening is the separate Sleep-apnea screening page (PhysioNet-trained).

Accepted: SensorTile .csv/.txt with accelerometer columns (QVAR/ECG not required), ≥ 120 s, measured rate 180–300 Hz. Invalid files are rejected with the reason. Typical processing time 10–60 s.

Known behaviour of this detector

Leave-one-event-out on session 1 (seed 0, whole-recording scan): 4 of 7 holds detected with 6 additional flagged segments (≈ 12 per hour of recording); quiet-breathing valleys are the main false flags. Models trained with augmentation + simulator windows detected 5/7 but with 22 extra segments, so the deployed model uses real windows only. Numbers: results/inhouse_bh/operating_points.csv.

Limitations

  • One volunteer, one labelled session (7 voluntary holds); no independent-subject evidence. Labels carry ±5 s boundary uncertainty; uncertain intervals were excluded from training.
  • Detects low chest-motion windows resembling voluntary holds. Quiet breathing, stillness or a sensor off the chest can also be flagged; this is not sleep-apnea detection and not diagnostic.
  • Second recording session (Mithin) has no verified alignment to the sensor logs, so it provides no labels.
